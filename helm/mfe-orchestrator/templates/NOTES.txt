{{- $env := .Values.env | default dict }}
{{- if not (get $env "NOSQL_DATABASE_URL") }}

WARNING: env.NOSQL_DATABASE_URL is not set. This chart does not deploy MongoDB,
so the application will try to reach a database on localhost and fail to start.
Set it with:

  --set env.NOSQL_DATABASE_URL="mongodb://user:password@my-mongodb:27017"
{{- end }}
{{- if not (get $env "REDIS_URL") }}

WARNING: env.REDIS_URL is not set. This chart does not deploy Redis, point the
application at your own instance:

  --set env.REDIS_URL="redis://my-redis:6379"
{{- end }}
{{- if and .Values.ingress.enabled (not (get (.Values.env | default dict) "TRUST_PROXY")) }}

NOTE: the ingress is enabled but env.TRUST_PROXY is not set. The backend only
trusts the nginx inside the pod, so every client is seen with the ingress
controller's IP and shares one rate limit bucket. Trust the ingress hop too, e.g.

  --set env.TRUST_PROXY="loopback\,10.0.0.0/8"
{{- end }}
{{- if and (get (.Values.env | default dict) "MCP_ENABLED") (not (get (.Values.env | default dict) "FRONTEND_URL")) }}

WARNING: env.MCP_ENABLED is set without env.FRONTEND_URL: the backend will not
start, as MCP clients have to be sent to the console's consent page.
{{- end }}
{{- if not (get (.Values.envSecrets | default dict) "JWT_SECRET") }}
{{- if not .Values.existingSecret }}

WARNING: envSecrets.JWT_SECRET is empty, so the application falls back to a
well-known default key. Set your own before exposing the console:

  --set envSecrets.JWT_SECRET="$(openssl rand -hex 32)"
{{- end }}
{{- end }}

All environment variables can be configured from values.yaml:

  envSecrets  sensitive variables   (rendered into a Secret)
  extraEnv    raw env entries, e.g. valueFrom references
